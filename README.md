1. システム名
　某育成ゲーム管理ツール

2. システム概要
 
 育成ゲームのキャラクター情報および鍛錬結果を管理するWebアプリケーション。
 利用者がキャラクター情報を登録・追加・削除できるほか、鍛錬結果を入力し育成状況を記録することが可能。
 最終的にはランキング機能も作成予定

3. 開発目的
   
　・チーム内でのキャラクター育成情報の共有化
　
 ・育成状況を記録・確認できるようにする
　
 ・Java、Spring Boot、MySQLの学習成果を形にする

5. 利用者
　管理者（自分と副大将）
　　・育成情報の管理
　　・鍛錬結果の閲覧
　チームのメンバー
　　・鍛錬結果の入力

6. 機能要件
　・育成結果入力画面
　　→育成結果を登録できる
　・キャラクター追加・削除画面
　　→新キャラクターが追加された際に登録でき、削除も可能
　・新アイテム追加・削除画面
　　→新アイテムが追加された際に登録でき、削除も可能
  ・育成結果確認画面
　　→他の人が入力したデータを閲覧できる

7. 非機能要件
　セキュリティ
　　なし
